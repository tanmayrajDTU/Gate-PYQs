Propositional & First-Order Logic

TRUTH TABLES · LOGICAL EQUIVALENCE · QUANTIFIERS · VALID INFERENCE

Propositional connectives

ConnectiveSymbolTrue when
AND (conjunction)p ∧ qBoth p and q true
OR (disjunction)p ∨ qAt least one true
NOT (negation)¬pp is false
Implicationp → qFalse only when p=T, q=F
Biconditionalp ↔ qp and q have the same truth value
Implication — the one everyone misreads

p → q is TRUE whenever p is false, regardless of q ("vacuously true"). It's only FALSE in the single case p=T, q=F. This single row is responsible for most GATE logic errors — always build the full truth table rather than reasoning informally about "if...then."

Key logical equivalences

De Morgan's: ¬(p∧q) ≡ ¬p∨¬q ¬(p∨q) ≡ ¬p∧¬q Contrapositive: p→q ≡ ¬q→¬p (equivalent; NOT the same as the converse q→p) Implication rewrite: p→q ≡ ¬p∨q Distributive: p∧(q∨r) ≡ (p∧q)∨(p∧r)
GATE trap

Converse (q→p), inverse (¬p→¬q), and contrapositive (¬q→¬p) of p→q are NOT all equivalent. Only the contrapositive is logically equivalent to the original. The converse and inverse are equivalent to each other, but not to the original statement.

First-order logic — quantifiers

∀x P(x) "for all x, P(x) holds" ∃x P(x) "there exists an x such that P(x) holds" Negating a quantifier flips it and negates inside: ¬(∀x P(x)) ≡ ∃x ¬P(x) ¬(∃x P(x)) ≡ ∀x ¬P(x)
Quantifier order matters

∀x ∃y P(x,y) and ∃y ∀x P(x,y) are generally NOT the same statement. The first says "for every x, some y works (possibly different for each x)." The second says "one single y works for every x." GATE frequently tests exactly this distinction with a concrete example.

Practice — GATE style (original)

5 questions
Q1 Is p → q logically equivalent to its converse q → p? Justify with a truth-value case.

No. Take p=F, q=T: p→q is T (vacuously), but q→p is F (T doesn't imply F). They disagree, so they are not equivalent in general.

Answer: Not equivalent

Q2 Simplify ¬(p ∧ ¬q) using De Morgan's law.

¬(p ∧ ¬q) = ¬p ∨ ¬(¬q) = ¬p ∨ q.

Answer: ¬p ∨ q

Q3 Negate the statement: ∀x ∃y (x + y = 0).

Flip both quantifiers and negate the inner statement: ¬(∀x ∃y (x+y=0)) = ∃x ∀y ¬(x+y=0) = ∃x ∀y (x+y≠0).

Answer: ∃x ∀y (x + y ≠ 0)

Q4 Is "∀x ∃y (y > x)" the same as "∃y ∀x (y > x)" over the real numbers?

No. The first ("for every x, some larger y exists") is TRUE over the reals. The second ("one y is larger than every x") is FALSE, since no real number exceeds all others. Order of quantifiers changes meaning and truth value.

Answer: Different statements, different truth values

Q5 Write the contrapositive of "If it rains, the ground is wet," and state whether it's logically equivalent to the original.

Contrapositive: "If the ground is not wet, it did not rain." The contrapositive is always logically equivalent to the original implication.

Answer: "If the ground is not wet, then it did not rain" — equivalent

Sets, Relations & Functions

RELATION PROPERTIES · EQUIVALENCE RELATIONS · FUNCTION TYPES

Properties of relations on a set A

PropertyCondition
Reflexive(a,a) ∈ R for every a ∈ A
Symmetric(a,b) ∈ R ⟹ (b,a) ∈ R
Antisymmetric(a,b)∈R and (b,a)∈R ⟹ a=b
Transitive(a,b)∈R and (b,c)∈R ⟹ (a,c)∈R
Equivalence relation

Reflexive + Symmetric + Transitive. Partitions the set into disjoint equivalence classes — every element belongs to exactly one class.

GATE trap

Symmetric and antisymmetric are NOT opposites — a relation can be both (e.g. equality) or neither. Don't assume "not symmetric" means "antisymmetric."

Function types

TypeCondition
Injective (one-one)f(a)=f(b) ⟹ a=b (distinct inputs → distinct outputs)
Surjective (onto)Every element of codomain has a preimage
BijectiveBoth injective and surjective — has a well-defined inverse
Counting functions between finite sets
|A|=m, |B|=n: Total functions A→B: nᵐ Injective functions (needs m≤n): n·(n−1)·...·(n−m+1) = nPm Bijective functions (needs m=n): n!

Practice — GATE style (original)

5 questions
Q1 R = {(a,a),(b,b),(c,c),(a,b),(b,a)} on {a,b,c}. Is R an equivalence relation?

Reflexive: all (x,x) present ✓. Symmetric: (a,b) and (b,a) both present ✓. Transitive: (a,b),(b,a)⟹ need (a,a) — present ✓. All three hold.

Answer: Yes, it's an equivalence relation (classes: {a,b}, {c})

Q2 How many functions exist from a set of size 3 to a set of size 5?

Total functions = nᵐ where m=3 (domain size), n=5 (codomain size): 5³.

Answer: 125

Q3 How many bijective functions exist from a set of size 4 to another set of size 4?

Bijections between equal-size finite sets = n! = 4! = 24.

Answer: 24

Q4 Is the "≤" relation on integers antisymmetric? Is it symmetric?

Antisymmetric: a≤b and b≤a ⟹ a=b — true. Symmetric: a≤b does NOT generally imply b≤a (e.g. 2≤3 but 3≰2) — false.

Answer: Antisymmetric, not symmetric

Q5 f: ℤ→ℤ defined by f(x) = 2x. Is f injective? Is f surjective onto ℤ?

Injective: f(a)=f(b) ⟹ 2a=2b ⟹ a=b — yes. Surjective onto ℤ: odd integers (like 3) have no preimage since 2x=3 has no integer solution — no.

Answer: Injective but not surjective

Partial Orders & Lattices

POSETS · HASSE DIAGRAMS · UPPER/LOWER BOUNDS · LATTICE STRUCTURE

Partially ordered set (poset)

A relation that is reflexive, antisymmetric, and transitive. Unlike a total order, not every pair of elements needs to be comparable — that's exactly what "partial" means.

Hasse diagram — reading it correctly

Draws only the "covering" relations (direct, non-redundant edges), with higher elements drawn above lower ones — reflexive loops and transitive edges are omitted by convention, not because they don't exist.

Bounds within a poset

TermDefinition
Upper bound of SAn element ≥ every element of S (need not be in S)
Least Upper Bound (LUB / join, ∨)The smallest of all upper bounds
Lower bound of SAn element ≤ every element of S
Greatest Lower Bound (GLB / meet, ∧)The largest of all lower bounds

Lattice

A poset in which every pair of elements has both a unique LUB (join) and a unique GLB (meet). This is stronger than being a poset — not every poset is a lattice.

GATE trap

A poset can have upper bounds for a subset without having a LUB, if multiple minimal upper bounds exist with none smaller than the others (they're incomparable to each other). This is exactly the failure mode GATE uses to construct "is this a lattice?" counter-examples — always check every pair, not just an obvious few.

Practice — GATE style (original)

5 questions
Q1 For the divisibility relation on {1,2,3,4,6,12}, find the LUB and GLB of {2,3}.

Upper bounds of {2,3} (divisible by both 2 and 3): 6, 12. Smallest is 6, so LUB=6. Lower bounds (divide both 2 and 3): only 1, so GLB=1.

Answer: LUB = 6, GLB = 1

Q2 Is the divisibility relation on positive integers a partial order? Justify briefly.

Reflexive: a|a always ✓. Antisymmetric: a|b and b|a ⟹ a=b (for positive integers) ✓. Transitive: a|b, b|c ⟹ a|c ✓. All three hold.

Answer: Yes, it's a partial order

Q3 In the power set of {a,b} ordered by ⊆, what is the LUB of {a} and {b}?

Upper bounds of {{a},{b}} under ⊆ must contain both {a} and {b} as subsets — the smallest such set is {a,b} itself.

Answer: LUB = {a,b}

Q4 Is (ℤ, ≤) — the integers under the usual ≤ order — a lattice?

Since ≤ is a total order (every pair is comparable), for any two integers a,b the LUB is simply max(a,b) and the GLB is min(a,b) — both always exist and are unique. Every total order is automatically a lattice.

Answer: Yes, it's a lattice (in fact a total order)

Q5 A poset has two incomparable minimal upper bounds for a subset S, and neither is smaller than the other. Does LUB(S) exist?

No — LUB requires a unique smallest upper bound. If two minimal upper bounds are incomparable (neither ≤ the other), there is no single smallest one, so LUB(S) does not exist even though upper bounds exist.

Answer: No, LUB does not exist in this case

04

Monoids & Groups

ALGEBRAIC STRUCTURE HIERARCHY · GROUP AXIOMS · ORDER OF AN ELEMENT

The structure hierarchy

StructureRequires
SemigroupClosure + Associativity
MonoidSemigroup + Identity element
GroupMonoid + every element has an Inverse
Abelian groupGroup + Commutativity

Each structure adds exactly one requirement on top of the previous — a group is automatically a monoid, semigroup, and closed binary structure, but not necessarily abelian.

Group axioms — checklist

1. Closure: a,b ∈ G ⟹ a*b ∈ G 2. Associativity: (a*b)*c = a*(b*c) 3. Identity: ∃e ∈ G such that a*e = e*a = a for all a 4. Inverse: ∀a ∈ G, ∃a⁻¹ ∈ G such that a*a⁻¹ = a⁻¹*a = e
Order of a group / order of an element

Order of the group = number of elements in it. Order of an element a = smallest positive integer n such that aⁿ = e (identity). In a finite group, the order of every element divides the order of the group (Lagrange's theorem) — a fast filter for what element orders are even possible. Note this is a necessary condition only: Lagrange's theorem doesn't by itself guarantee that every divisor of the group's order is actually realized as some element's order — that requires additional, group-specific structural facts (e.g. cyclicity).

GATE trap

(ℕ, +) — natural numbers under addition — is a monoid (has identity 0) but NOT a group, since no positive integer has an additive inverse within ℕ. Always check the inverse requirement explicitly; closure, associativity, and even identity being present is not enough.

Practice — GATE style (original)

5 questions
Q1 Is (ℤ, +) a group? Identify the identity and the inverse of an element a.

Closure ✓ (sum of integers is an integer), associativity ✓, identity = 0 (a+0=a) ✓, inverse of a is −a (a+(−a)=0) ✓, and it's abelian too.

Answer: Yes, (ℤ,+) is an abelian group; identity=0, inverse of a is −a

Q2 Is (ℤ, ×) — integers under multiplication — a group?

Closure ✓, associativity ✓, identity = 1 ✓. But inverse fails: e.g. 2 has no integer x with 2×x=1. Not every element has a multiplicative inverse in ℤ.

Answer: No — it's a monoid, not a group (inverse fails)

Q3 In a group of order 15, which element orders are permitted by Lagrange's theorem?

By Lagrange's theorem, every element's order must divide the group's order — this gives a necessary condition (a fast filter for what's possible), not a guarantee that every divisor is actually realized by some element. Divisors of 15: 1, 3, 5, 15.

(As a separate, deeper fact beyond Lagrange alone: since 15 = 3×5 with 3 and 5 prime and 3∤(5−1), every group of order 15 is in fact cyclic — and a cyclic group of order n does have an element of every order dividing n, so for this specific order all four permitted values 1, 3, 5, 15 do actually occur. That conclusion needs more than Lagrange's theorem by itself, though.)

Answer: Orders permitted by Lagrange's theorem: 1, 3, 5, 15 (and for order 15 specifically, all four are also known to actually occur, though that requires more than Lagrange's theorem alone)

Q4 Find the order of the element 2 in the group (ℤ₆, +) [integers mod 6 under addition, identity=0].

Compute multiples of 2 mod 6 until reaching 0: 2, 4, 6≡0. It took 3 additions to reach identity.

Answer: Order of 2 is 3

Q5 Is every group abelian? Give a structural reason why not, referencing the axioms.

No — commutativity (a*b=b*a) is not one of the four group axioms (closure, associativity, identity, inverse), so it's an extra property some groups have and others don't. Matrix multiplication groups are a standard example of non-abelian groups.

Answer: No — commutativity is not a required group axiom

Graph Theory

CONNECTIVITY · MATCHING · COLOURING · HANDSHAKE LEMMA

Handshake lemma — the fastest sanity check

Σ (degree of all vertices) = 2 × (number of edges)

A direct consequence: the number of vertices with odd degree is always even. GATE frequently gives a degree sequence and asks whether such a graph can exist — this lemma is the first check.

Connectivity

TermMeaning
Connected graphA path exists between every pair of vertices
Cut vertex / cut edgeRemoving it disconnects the graph
k-connectedRemains connected after removing any k−1 vertices

Matching

A matching is a set of edges with no shared vertices. A maximum matching has the most edges possible; a perfect matching covers every vertex exactly once (requires an even number of vertices).

Bipartite matching — Hall's theorem

A bipartite graph (X,Y) has a matching saturating every vertex of X iff for every subset S⊆X, |N(S)| ≥ |S| (the neighborhood of S is at least as large as S) — this is Hall's Marriage Theorem, a common GATE-adjacent proof technique.

Graph colouring

Chromatic number χ(G) = minimum colours needed so no two adjacent vertices share a colour.

Graph typeChromatic number
Complete graph Kₙn
Bipartite graph (with ≥1 edge)2
Cycle with even length2
Cycle with odd length3
Tree (any, with ≥1 edge)2
GATE trap

χ(G) ≥ ω(G) always (chromatic number is at least the size of the largest clique), but they are NOT always equal — some graphs need strictly more colours than their largest clique size (e.g. odd cycles: clique number 2, chromatic number 3). Don't assume clique number gives the exact chromatic number.

Practice — GATE style (original)

5 questions
Q1 A graph has 6 edges. What is the sum of degrees of all vertices?

By the handshake lemma, sum of degrees = 2 × edges = 2 × 6.

Answer: 12

Q2 Can a simple graph exist with degree sequence (3,3,3,1)?

Sum = 3+3+3+1 = 10 (even) and the odd-degree vertex count is 4 (even), so it passes both parity checks — but passing parity is necessary, not sufficient. Applying Havel–Hakimi: remove the first 3, subtract 1 from the next three degrees: (3,3,1) → (2,2,0). Remove the new first term (2), subtract 1 from the next two: (2,0) → (1,−1). A negative degree is impossible, so the sequence is not graphical. (Intuitively: on 4 vertices, three vertices of degree 3 must each connect to all other 3 vertices, forcing the 4th vertex to degree 3 as well — degree 1 is unreachable.)

Answer: No — despite passing the parity checks, Havel–Hakimi reduces (3,3,3,1) to an invalid (1,−1), so no simple graph exists with this degree sequence

Q3 Find the chromatic number of the complete graph K₅.

Every pair of vertices in a complete graph is adjacent, so all n vertices need distinct colours. χ(Kₙ)=n.

Answer: χ(K₅) = 5

Q4 Find the chromatic number of a 5-cycle (C₅).

Odd-length cycles cannot be 2-coloured (you'd need to alternate colours around an odd loop, which forces two adjacent vertices to share a colour at the closing edge), but 3 colours always suffice for any cycle.

Answer: χ(C₅) = 3

Q5 A tree has 10 vertices. How many edges does it have, and what is its chromatic number?

Every tree with n vertices has exactly n−1 edges: 10−1=9 edges. Trees are bipartite (no odd cycles, since they have no cycles at all), so χ=2 (for any tree with at least one edge).

Answer: 9 edges, chromatic number = 2

Combinatorics

COUNTING PRINCIPLES · RECURRENCE RELATIONS · GENERATING FUNCTIONS

Core counting principles

Pigeonhole principle

If n items are placed into k boxes and n > k, at least one box has ≥2 items. GATE often disguises this as "prove some two things must share a property."

Inclusion-Exclusion (2 sets)
|A∪B| = |A|+|B|−|A∩B|

Extends to 3 sets: |A∪B∪C| = |A|+|B|+|C|−|A∩B|−|B∩C|−|A∩C|+|A∩B∩C|.

Solving linear recurrence relations

For a homogeneous linear recurrence like aₙ = c₁aₙ₋₁ + c₂aₙ₋₂, write the characteristic equation and solve for its roots:

aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ ⟹ x² − c₁x − c₂ = 0 Distinct real roots r₁,r₂: aₙ = A·r₁ⁿ + B·r₂ⁿ Repeated root r: aₙ = (A + Bn)·rⁿ (constants A, B fixed using initial conditions a₀, a₁)
Worked example — Fibonacci-style

aₙ = aₙ₋₁ + aₙ₋₂ ⟹ x²−x−1=0 ⟹ x = (1±√5)/2 (the golden ratio and its conjugate). This is exactly how the closed-form Fibonacci formula (Binet's formula) is derived.

Generating functions — the compact representation

A generating function encodes a whole sequence a₀,a₁,a₂,... as coefficients of a power series:

G(x) = Σ aₙxⁿ = a₀ + a₁x + a₂x² + ...

Useful for solving recurrences algebraically and for counting problems where the answer is "coefficient of xᵏ in some product of series."

GATE trap

For a repeated root r in the characteristic equation, the general solution is (A + Bn)·rⁿ — NOT simply A·rⁿ. Forgetting the extra factor of n for repeated roots is one of the most common recurrence-solving mistakes.

Practice — GATE style (original)

5 questions
Q1 25 pigeons occupy 24 pigeonholes. What can you conclude?

By the pigeonhole principle, since 25 > 24, at least one pigeonhole must contain at least 2 pigeons.

Answer: At least one hole has ≥ 2 pigeons

Q2 In a class of 50, 30 like Maths, 25 like Physics, and 15 like both. How many like at least one subject?

|M∪P| = |M|+|P|−|M∩P| = 30+25−15.

Answer: 40 students

Q3 Solve the recurrence aₙ = 5aₙ₋₁ − 6aₙ₋₂ with a₀=1, a₁=4.

Characteristic equation: x²−5x+6=0 ⟹ (x−2)(x−3)=0 ⟹ roots 2,3. General solution aₙ=A·2ⁿ+B·3ⁿ. Using a₀=1: A+B=1. Using a₁=4: 2A+3B=4. Solve: from first, A=1−B; substitute: 2(1−B)+3B=4 ⟹ 2+B=4 ⟹ B=2, A=−1.

Answer: aₙ = −2ⁿ + 2·3ⁿ

Q4 Solve the recurrence aₙ = 4aₙ₋₁ − 4aₙ₋₂ with a₀=1, a₁=4 (note: repeated root case).

Characteristic equation: x²−4x+4=0 ⟹ (x−2)²=0 ⟹ repeated root r=2. General solution: aₙ=(A+Bn)·2ⁿ. a₀=1: A=1. a₁=4: (A+B)·2=4 ⟹ A+B=2 ⟹ B=1.

Answer: aₙ = (1 + n)·2ⁿ

Q5 In a group of 13 people, must at least two share a birth month? Justify.

There are 12 possible birth months (pigeonholes) and 13 people (pigeons). Since 13 > 12, by the pigeonhole principle at least two people must share a birth month.

Answer: Yes, guaranteed by the pigeonhole principle

Revision Sheet

EVERYTHING ON ONE SCREEN — LAST-MINUTE PASS
Implication truth table

p→q is false only when p=T, q=F. Contrapositive (¬q→¬p) is equivalent; converse and inverse are not.

De Morgan's & quantifier negation

¬(p∧q)≡¬p∨¬q. ¬(∀xP(x))≡∃x¬P(x). Quantifier order changes meaning: ∀x∃y ≠ ∃y∀x in general.

Relation properties

Equivalence = reflexive+symmetric+transitive (partitions the set). Symmetric ≠ opposite of antisymmetric.

Counting functions

|A|=m,|B|=n: total=nᵐ, injective (m≤n)=nPm, bijective (m=n)=n!.

Lattice

Poset where every pair has a unique LUB (join) and GLB (meet). Not every poset is a lattice — check for incomparable minimal upper bounds.

Group axioms

Closure, Associativity, Identity, Inverse. Monoid = first three only (no inverse required). Lagrange: element order divides group order (necessary, not sufficient — not every divisor is guaranteed to be realized).

Handshake lemma

Σdegrees = 2×edges. Number of odd-degree vertices is always even.

Chromatic number

χ(Kₙ)=n. χ(bipartite/tree/even cycle)=2. χ(odd cycle)=3. χ(G)≥ω(G) but not always equal.

Pigeonhole & inclusion-exclusion

n items, k boxes, n>k ⟹ some box has ≥2. |A∪B|=|A|+|B|−|A∩B|.

Linear recurrence — distinct roots

x²−c₁x−c₂=0, roots r₁≠r₂ ⟹ aₙ=A·r₁ⁿ+B·r₂ⁿ. Solve A,B using a₀,a₁.

Linear recurrence — repeated root

Repeated root r ⟹ aₙ=(A+Bn)·rⁿ — don't forget the extra n factor.

Generating functions

G(x)=Σaₙxⁿ encodes a whole sequence — coefficient extraction solves counting/recurrence problems algebraically.

Practice — rapid-fire mix (original)

5 questions
Q1 Is "∀x (P(x) → Q(x))" the same as "(∀x P(x)) → (∀x Q(x))"?

No, not in general — the first requires the implication to hold individually for each x, while the second only requires that if P holds for ALL x, then Q holds for ALL x (a much weaker global statement). The first implies the second, but not conversely.

Answer: Not equivalent (first is stronger)

Q2 A relation is symmetric and antisymmetric simultaneously. What must be true of it?

Symmetric means (a,b)∈R ⟹ (b,a)∈R. Antisymmetric means (a,b)∈R and (b,a)∈R ⟹ a=b. Combined: whenever (a,b)∈R, we also get (b,a)∈R, forcing a=b. So R can only contain pairs of the form (a,a).

Answer: R must be a subset of the identity relation (only (a,a) pairs)

Q3 A graph has 7 vertices each of degree 4. How many edges does it have?

Sum of degrees = 7×4 = 28. Edges = sum/2 = 28/2.

Answer: 14 edges

Q4 Is (ℚ⁺, ×) — positive rationals under multiplication — a group?

Closure ✓ (product of positive rationals is a positive rational), associativity ✓, identity=1 ✓, and every positive rational p/q has inverse q/p, also a positive rational ✓. All four axioms hold, and it's abelian too.

Answer: Yes, (ℚ⁺,×) is an abelian group

Q5 How many ways can you select 3 books from 8 different books to give to 3 different friends (one each)?

Order matters here since each friend gets a distinct book (different assignment = different outcome) — this is a permutation, not a combination. 8P3 = 8×7×6.

Answer: 336 ways
