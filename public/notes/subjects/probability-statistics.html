Probability Basics & Conditional Probability

SAMPLE SPACE · AXIOMS · ADDITION RULE · CONDITIONAL · INDEPENDENCE

Axioms of Probability

For any event A in sample space S:

1. 0 ≤ P(A) ≤ 1 2. P(S) = 1 3. For mutually exclusive events A and B: P(A ∪ B) = P(A) + P(B)

Addition and Multiplication Rules

Addition Rule: P(A ∪ B) = P(A) + P(B) − P(A ∩ B) Multiplication Rule: P(A ∩ B) = P(A) · P(B|A) = P(B) · P(A|B)

Conditional Probability & Independence

The probability of event A given that event B has occurred:

P(A|B) = P(A ∩ B) / P(B), provided P(B) > 0

Two events A and B are independent if knowing that B happened gives no information about A. This translates to P(A|B) = P(A), which gives:

P(A ∩ B) = P(A) · P(B) (iff A and B are independent)
GATE trap

Do NOT confuse "independent events" with "mutually exclusive events". Mutually exclusive means they cannot happen together (P(A ∩ B) = 0). Independent means the occurrence of one doesn't affect the probability of the other (P(A ∩ B) = P(A)P(B)). In fact, if A and B are mutually exclusive (with non-zero probabilities), they are mathematically guaranteed to be dependent.

Conditional independence

A and B are conditionally independent given C if, once you already know C occurred, learning A gives no further information about B (and vice versa):

P(A ∩ B | C) = P(A|C) · P(B|C)
Conditional independence ≠ unconditional independence

These are genuinely different properties, and neither implies the other. A and B can be conditionally independent given C, yet be dependent when C is unknown/unconditioned on — and conversely, A and B can be unconditionally independent yet become dependent once you condition on some C. A classic example: A = "sprinkler was on", B = "grass is wet from rain", C = "the ground is wet". A and B may look correlated unconditionally (both tend to coincide with "wet ground" scenarios), but once C is fixed, learning about the sprinkler tells you nothing extra about whether it rained, or vice versa. This is exactly the reasoning pattern behind Bayesian-network-style questions: an edge structure encodes exactly which variables are conditionally independent given which others, and GATE questions often hinge on spotting this distinction rather than computing a number.

Practice — GATE style (original)

5 questions
Q1 Let P(A) = 0.4, P(B) = 0.5, and P(A ∪ B) = 0.7. Are A and B independent?

First find P(A ∩ B) using the addition rule: P(A ∪ B) = P(A) + P(B) − P(A ∩ B) ⇒ 0.7 = 0.4 + 0.5 − P(A ∩ B) ⇒ P(A ∩ B) = 0.2.

Now check for independence: P(A)P(B) = (0.4)(0.5) = 0.2. Since P(A ∩ B) = P(A)P(B), the events are independent.

Answer: Yes

Q2 A fair coin is tossed 3 times. What is the probability of getting exactly 2 heads given that the first toss is a head?

Let B = "first toss is a head" = {HHH, HHT, HTH, HTT}. P(B) = 4/8.

Let A = "exactly 2 heads". A ∩ B = "first toss is head AND exactly 2 heads" = {HHT, HTH}. P(A ∩ B) = 2/8.

P(A|B) = P(A ∩ B) / P(B) = (2/8) / (4/8) = 2/4 = 1/2.

Answer: 1/2

Q3 If A and B are mutually exclusive and P(A) > 0, P(B) > 0, find P(A|B).

Mutually exclusive means P(A ∩ B) = 0. By definition, P(A|B) = P(A ∩ B) / P(B) = 0 / P(B) = 0.

Answer: 0

Q4 A bag contains 4 red and 6 blue balls. Two balls are drawn without replacement. What is the probability both are red?

Let R₁ be the event the first is red, R₂ the event the second is red.

P(R₁ ∩ R₂) = P(R₁) · P(R₂|R₁) = (4/10) · (3/9) = 12/90 = 2/15.

Answer: 2/15

Q5 Let P(A) = 0.3, P(A ∪ B) = 0.6. Find P(B) if A and B are independent.

Since A and B are independent, P(A ∩ B) = P(A)P(B) = 0.3 · P(B).

Addition rule: P(A ∪ B) = P(A) + P(B) − P(A ∩ B) ⇒ 0.6 = 0.3 + P(B) − 0.3 · P(B).

0.3 = 0.7 · P(B) ⇒ P(B) = 0.3 / 0.7 = 3/7.

Answer: 3/7

02

Bayes' Theorem

TOTAL PROBABILITY · BAYES' RULE · POSTERIOR PROBABILITY

Law of Total Probability

If A₁, A₂, ..., Aₙ form a partition of the sample space (mutually exclusive and exhaustive), then for any event B:

P(B) = ∑ P(B|Aᵢ)P(Aᵢ) for i = 1 to n

Bayes' Theorem

It reverses the condition: given that B has occurred, what is the probability it was caused by Aᵢ?

P(Aᵢ|B) = [ P(B|Aᵢ)P(Aᵢ) ] / P(B)

Where P(B) is calculated using the Law of Total Probability.

Terminology: P(Aᵢ) is the prior probability, P(B|Aᵢ) is the likelihood, and P(Aᵢ|B) is the posterior probability.

GATE trap

In total probability / Bayes' problems, a common mistake is forgetting to account for ALL partitions when calculating the denominator P(B). Always verify that your A₁, A₂, ..., Aₙ probabilities sum to 1. E.g., if checking for a defective item from machines X, Y, Z, ensure you include the defect paths from all three machines.

Conditional Expectation & Law of Total Expectation

Conditional expectation E[X|A] is the expected value of X restricted to the outcomes where event A has occurred — computed the same way as an ordinary expectation, but using the conditional distribution of X given A instead of its unconditional distribution.

If A₁, A₂, ..., Aₙ form a partition of the sample space (same setup as the Law of Total Probability), the Law of Total Expectation lets you build E[X] from the conditional expectations on each piece of the partition, weighted by how likely each piece is:

E[X] = ∑ E[X|Aᵢ] P(Aᵢ) for i = 1 to n

This mirrors the Law of Total Probability exactly, with E[X|Aᵢ] playing the role that P(B|Aᵢ) played there. It's useful whenever a random variable's behavior naturally splits across a few cases/conditions (e.g. expected defect cost when items come from different machines, or expected wait time given which of several servers picks up a request) and it's easier to reason about each case separately than about X directly.

Practice — GATE style (original)

5 questions
Q1 Machine X produces 60% of items and Machine Y produces 40%. 2% of X's output is defective, and 3% of Y's is defective. Find the total probability an item is defective.

P(Defect) = P(D|X)P(X) + P(D|Y)P(Y) = (0.02)(0.60) + (0.03)(0.40) = 0.012 + 0.012 = 0.024 (or 2.4%).

Answer: 0.024

Q2 In the previous question, if an item is found defective, what is the probability it came from Machine Y?

Using Bayes' theorem: P(Y|D) = P(D|Y)P(Y) / P(D) = (0.03)(0.40) / 0.024 = 0.012 / 0.024 = 1/2.

Answer: 0.5

Q3 A disease affects 1% of a population. A test has 99% sensitivity (correctly positive when diseased) and 99% specificity (correctly negative when healthy). If a person tests positive, what is the probability they actually have the disease?

Let D = disease, H = healthy. P(D) = 0.01, P(H) = 0.99. Sensitivity gives P(+|D) = 0.99; specificity gives P(-|H) = 0.99, so P(+|H) = 0.01.

P(+) = P(+|D)P(D) + P(+|H)P(H) = (0.99)(0.01) + (0.01)(0.99) = 0.0198.

P(D|+) = P(+|D)P(D) / P(+) = 0.0099 / 0.0198 = 1/2 = 50%.

Answer: 0.5 (or 50%)

Q4 Urn 1 has 3 red and 4 black balls. Urn 2 has 5 red and 6 black balls. A fair die is rolled: if it shows 1 or 2, Urn 1 is chosen; otherwise Urn 2. A ball is drawn and is red. Probability it was Urn 1?

P(U₁) = 2/6 = 1/3, P(U₂) = 4/6 = 2/3. P(R|U₁) = 3/7, P(R|U₂) = 5/11.

P(R) = (3/7)(1/3) + (5/11)(2/3) = 1/7 + 10/33 = 33/231 + 70/231 = 103/231.

P(U₁|R) = P(R|U₁)P(U₁) / P(R) = (1/7) / (103/231) = (33/231) / (103/231) = 33/103.

Answer: 33/103

Q5 A student knows the answer to a multiple choice question with probability 0.6; otherwise (probability 0.4) they guess. There are 4 options. If they got it right, what's the probability they actually knew it?

Let K = knows, G = guesses. P(K) = 0.6, P(G) = 0.4. P(Correct|K) = 1 (assuming knowing means getting it right). P(Correct|G) = 1/4 = 0.25.

P(C) = P(C|K)P(K) + P(C|G)P(G) = (1)(0.6) + (0.25)(0.4) = 0.6 + 0.1 = 0.7.

P(K|C) = P(C|K)P(K) / P(C) = 0.6 / 0.7 = 6/7.

Answer: 6/7

03

Random Variables

DISCRETE VS CONTINUOUS · PMF/PDF · CDF · EXPECTATION & VARIANCE

PMF, PDF, and CDF

Discrete RV (PMF): P(X = x). Must satisfy P(x) ≥ 0 and ∑ P(x) = 1.

Continuous RV (PDF): f(x). Must satisfy f(x) ≥ 0 and ∫ f(x)dx = 1 over the domain. The probability at an exact point is 0; we calculate probability over intervals: P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx.

Cumulative Distribution Function (CDF)
F(x) = P(X ≤ x)

Properties: Non-decreasing, right-continuous, lim(x→−∞)F(x) = 0, lim(x→∞)F(x) = 1.

For continuous RVs: f(x) = d/dx F(x).

Expectation and Variance

Expectation (Mean, μ):

Discrete: E[X] = ∑ xᵢ·P(xᵢ) Continuous: E[X] = ∫ x·f(x)dx

Variance (σ²) and Standard Deviation (σ):

Var(X) = E[ (X − μ)² ] = E[X²] − (E[X])² σ = √Var(X)

Properties of Expectation and Variance

E[aX + b] = aE[X] + b Var(aX + b) = a²Var(X) E[X + Y] = E[X] + E[Y] (always holds) Var(X + Y) = Var(X) + Var(Y) (if X,Y are independent)

Covariance and Correlation

Cov(X,Y) = E[XY] − E[X]E[Y] Cov(X,X) = Var(X) (a variance is just a variable's covariance with itself)

Covariance generalizes the variance-of-a-sum formula above to the general (not-necessarily-independent) case:

Var(X + Y) = Var(X) + Var(Y) + 2·Cov(X,Y)

This collapses to the earlier independent-case formula only because independence forces Cov(X,Y) = 0 — the "if X,Y are independent" caveat above is really just this general formula with its cross-term dropped.

Correlation coefficient (ρ)
ρ = Cov(X,Y) / (σ_X · σ_Y), −1 ≤ ρ ≤ 1

Correlation is covariance rescaled to be unit-free and bounded — it measures the strength and direction of the linear relationship between X and Y, independent of either variable's own units or scale.

GATE trap — ρ is undefined (not zero) when either variance is zero

The formula divides by σ_X·σ_Y, so ρ is only defined when σ_X > 0 AND σ_Y > 0. A constant random variable (one that takes a single fixed value with probability 1, e.g. X ≡ 5 always) has Var(X) = 0, hence σ_X = 0 — its correlation with any other variable Y is a division by zero, and is therefore undefined, not 0. Don't report ρ = 0 for a constant just because Cov(X,Y) also happens to be 0 in that case (a constant's covariance with anything is indeed always 0) — the correct statement is that the ratio 0/0 is undefined, and "correlation" simply doesn't apply to a variable with no variance at all.

GATE trap — Cov(X,Y)=0 (or ρ=0) does NOT imply independence

Independence is a strictly stronger condition than zero covariance. Independence ⟹ Cov(X,Y)=0 always, but the converse is false in general: X and Y can be strongly, even deterministically, related through a non-linear relationship and still have zero covariance, because covariance/correlation only capture linear association. Classic example: let X be uniform on [−1,1] and Y = X². Y is completely determined by X — about as dependent as two variables can be — yet Cov(X,Y) = E[X³] − E[X]·E[X²] = 0 − 0 = 0, since both E[X³] and E[X] vanish for a distribution symmetric about 0. Zero correlation only rules out a linear relationship; it says nothing about non-linear dependence.

GATE trap

For continuous variables, the PDF f(x) is a density, not a probability. While probabilities must be ≤ 1, a PDF value can easily exceed 1! Example: Uniform distribution on [0, 0.5] has f(x) = 2. Never eliminate an option just because f(x) > 1.

Practice — GATE style (original)

5 questions
Q1 Find k such that f(x) = kx for 0 < x < 2 is a valid PDF.

Must integrate to 1. ∫₀² kx dx = k[x²/2]₀² = k(2) = 1. Therefore, k = 1/2.

Answer: 1/2

Q2 A discrete RV has P(X=0)=0.2, P(X=1)=0.5, P(X=2)=0.3. Find E[X] and E[X²].

E[X] = 0(0.2) + 1(0.5) + 2(0.3) = 0 + 0.5 + 0.6 = 1.1.

E[X²] = 0²(0.2) + 1²(0.5) + 2²(0.3) = 0 + 0.5 + 1.2 = 1.7.

Answer: E[X] = 1.1, E[X²] = 1.7

Q3 If Var(X) = 4, find Var(3X + 5).

Using the property Var(aX + b) = a²Var(X).

Var(3X + 5) = 3²Var(X) = 9(4) = 36.

Answer: 36

Q4 Find the CDF F(x) for the PDF f(x) = 2x for 0 < x < 1, and 0 otherwise.

For x < 0, F(x) = 0.

For 0 ≤ x ≤ 1, F(x) = ∫₀ˣ 2t dt = [t²]₀ˣ = x².

For x > 1, F(x) = 1.

Answer: F(x) = x² on [0,1], 0 for x<0, 1 for x>1

Q5 If X and Y are independent random variables with Var(X)=2 and Var(Y)=3, find Var(2X - Y).

Var(2X - Y) = Var(2X) + Var(-Y) (since independent) = 2²Var(X) + (-1)²Var(Y) = 4(2) + 1(3) = 8 + 3 = 11.

Answer: 11

Standard Discrete Distributions

BINOMIAL · POISSON · POISSON APPROXIMATION · GEOMETRIC

Binomial Distribution — B(n,p)

Models the number of successes in n independent Bernoulli trials, each with probability of success p.

PMF: P(X = k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ Mean: μ = np Variance: σ² = np(1−p)

Poisson Distribution — Poisson(λ)

Models the number of events occurring in a fixed interval of time or space, when events occur with a known constant mean rate λ and independently of the time since the last event.

PMF: P(X = k) = e⁻λ · λᵏ / k! Mean: μ = λ Variance: σ² = λ
Poisson Approximation to Binomial

As a quick rule of thumb: when n is very large and p is very small, calculating the Binomial PMF directly is computationally awkward, and the Poisson distribution with λ = np approximates it well.

The precise limiting statement behind this rule: for Binomial(n, p) as n → ∞ and p → 0 while np → λ stays fixed and finite, the Binomial PMF converges to the Poisson(λ) PMF. The "np held fixed" condition is the part GATE expects you to know — n large and p small on their own aren't enough if their product isn't a moderate, stable value.

Geometric Distribution — Geom(p) 🟡 supporting / historical

Not explicitly named in the revised GATE CSE 2027 probability syllabus (which lists Uniform, Normal, Exponential, Poisson, Binomial, random variables, mean/median/mode/SD, conditional probability, and Bayes) — kept here because it's a well-established, frequently useful distribution and has appeared in past GATE papers, but treat it as supporting material rather than a core syllabus item.

Models the number of independent Bernoulli(p) trials needed to get the first success. This is the "trial number of first success" convention — the one GATE uses by default unless a question says otherwise.

PMF: P(X = k) = (1−p)^(k−1) p , k = 1, 2, 3, ... Mean: μ = 1/p Variance: σ² = (1−p)/p²
Watch for the other convention

Some textbooks instead define the geometric random variable as the number of failures before the first success, with support k = 0, 1, 2, ... In that convention: P(X=k) = (1−p)^k p, mean = (1−p)/p, and variance is unchanged at (1−p)/p². Same distribution, shifted by 1 — always check which convention a question is using before quoting mean/PMF, since mixing them up is a common, entirely avoidable error.

Memoryless property

The geometric distribution is the only discrete distribution with the memoryless property: P(X > m+n | X > m) = P(X > n) for all m, n ≥ 0. Having already failed m trials tells you nothing about how many more trials remain — the process "forgets" how long it's been waiting.

GATE trap — Mean = Variance does NOT imply Poisson

For a known Poisson(λ) distribution, E[X] = Var(X) = λ — that direction is a true, useful fact. But the converse is false: "mean equals variance" does not identify a distribution as Poisson, because it isn't a characterizing property. Other discrete random variables can satisfy E[X] = Var(X) too (constructed examples exist outside the standard named families), so mean=variance is at most a piece of supporting evidence for Poisson, never proof. Don't reason backward from "mean = variance" to "must be Poisson" — only reason forward, from "given Poisson" to "mean = variance = λ."

Practice — GATE style (original)

5 questions
Q1 A fair coin is tossed 10 times. What is the probability of getting exactly 5 heads?

Binomial with n=10, p=0.5, k=5. P(X=5) = C(10,5)(0.5)⁵(0.5)⁵ = (252) / 2¹⁰ = 252/1024 = 63/256.

Answer: 63/256 ≈ 0.246

Q2 A call center receives an average of 3 calls per minute. What is the probability of receiving exactly 2 calls in a given minute?

Poisson with λ=3. P(X=2) = e⁻³ · 3² / 2! = 9e⁻³ / 2 = 4.5e⁻³.

Answer: 4.5e⁻³

Q3 The probability of a defective item is 0.01. In a batch of 200 items, find the approximate probability of getting exactly 2 defective items using Poisson.

Here n=200, p=0.01. So λ = np = 2. Use Poisson PMF for k=2: P(X=2) = e⁻² · 2² / 2! = 4e⁻² / 2 = 2e⁻².

Answer: 2e⁻²

Q4 For a binomial random variable X, if the mean is 4 and the variance is 3, find n and p.

μ = np = 4. Var = np(1−p) = 3.

Substitute np=4 into the variance equation: 4(1−p) = 3 ⇒ 1−p = 3/4 ⇒ p = 1/4.

Then n(1/4) = 4 ⇒ n = 16.

Answer: n = 16, p = 1/4

Q5 If X follows a Poisson distribution such that P(X=1) = P(X=2), find P(X=4).

P(X=1) = e⁻λλ¹/1! = λe⁻λ. P(X=2) = e⁻λλ²/2! = (λ²/2)e⁻λ.

Equating them: λe⁻λ = (λ²/2)e⁻λ ⇒ 1 = λ/2 (since λ>0) ⇒ λ = 2.

Now find P(X=4) = e⁻² · 2⁴ / 4! = 16e⁻² / 24 = (2/3)e⁻².

Answer: (2/3)e⁻²

Standard Continuous Distributions

UNIFORM · EXPONENTIAL · NORMAL · MEMORYLESS PROPERTY

Uniform Distribution — U(a,b)

Constant probability density over the interval [a, b].

PDF: f(x) = 1/(b−a) for x ∈ [a,b] Mean: μ = (a+b)/2 Variance: σ² = (b−a)²/12

Exponential Distribution — Exp(λ)

Models the time between events in a Poisson process.

PDF: f(x) = λe⁻λˣ for x ≥ 0 CDF: F(x) = 1 − e⁻λˣ Mean: μ = 1/λ Variance: σ² = 1/λ²
The Memoryless Property

The exponential distribution is the ONLY continuous distribution with this property. P(X > s+t | X > s) = P(X > t). In plain terms: if you've waited 's' minutes, the probability you have to wait 't' more minutes is exactly the same as if you just started waiting.

Normal Distribution — N(μ,σ²)

The classic bell curve. Symmetric about the mean μ. The sum of independent normal RVs is also normal.

PDF: f(x) = (1 / √(2πσ²)) · e^(−(x−μ)² / (2σ²)) Standard Normal (Z): Z ~ N(0,1), formed by Z = (X−μ)/σ Empirical Rule: 68% in ±1σ, 95% in ±2σ, 99.7% in ±3σ

Uniform(a+b)/2(b−a)²/12
Exponential1/λ1/λ²

GATE trap

When computing probabilities for a Normal Distribution, ALWAYS convert it to the standard normal Z first using Z = (X−μ)/σ. GATE will provide the Φ(Z) values (the standard normal CDF values) in the question or useful data section.

Practice — GATE style (original)

5 questions
Q1 X is uniformly distributed on [2, 8]. Find P(X > 6).

PDF f(x) = 1/(8−2) = 1/6. P(X > 6) = ∫₆⁸ (1/6) dx = (1/6)[8 − 6] = 2/6 = 1/3.

Answer: 1/3

Q2 The time to failure of a machine follows an exponential distribution with a mean of 5 years. Find the probability it survives past 5 years.

Mean = 1/λ = 5 ⇒ λ = 1/5 = 0.2. CDF F(x) = P(X ≤ x) = 1 − e⁻λˣ.

P(X > 5) = 1 − P(X ≤ 5) = e⁻⁰·²⁽⁵⁾ = e⁻¹.

Answer: e⁻¹ ≈ 0.368

Q3 (Continuing Q2) If the machine has already survived 3 years, what is the probability it survives 5 more years?

Due to the memoryless property of the exponential distribution, P(X > 3+5 | X > 3) = P(X > 5). This is identical to the previous answer.

Answer: e⁻¹ ≈ 0.368

Q4 X is a normally distributed RV with μ = 50 and σ = 10. Find P(X < 70) in terms of the standard normal CDF Φ.

Convert to standard normal: Z = (X − μ) / σ = (70 − 50) / 10 = 20 / 10 = 2.

P(X < 70) = P(Z < 2) = Φ(2).

Answer: Φ(2)

Q5 If X ~ N(μ=2, σ²=4) and Y ~ N(μ=3, σ²=5) are independent, what is the distribution of Z = X + Y?

Note: N(μ, σ²) is used here — the second parameter is the variance, not the standard deviation (some texts use N(μ, σ) instead, so always check which convention a problem uses).

The sum of independent normal RVs is also normal. The means add: μ_z = μ_x + μ_y = 2 + 3 = 5. The variances add: σ²_z = σ²_x + σ²_y = 4 + 5 = 9. So Z ~ N(μ=5, σ²=9).

Answer: Normal with mean 5, variance 9

Descriptive Statistics

MEAN · MEDIAN · MODE · STANDARD DEVIATION · TRANSFORMATIONS

Measures of Central Tendency

Mean (Arithmetic): Sum of all values divided by n. Highly affected by outliers.

Median: The middle value when sorted. Robust to outliers. If n is even, it's the average of the two middle values.

Mode: The most frequently occurring value(s).

Empirical Relationship

For moderately skewed, unimodal distributions:

Mode ≈ 3 · Median − 2 · Mean

This is Pearson's empirical approximation, not an exact identity — it's a rough estimate that holds reasonably well for moderately skewed unimodal distributions, not a formula derivable from first principles for arbitrary data.

Measures of Dispersion

Standard Deviation (σ): The square root of the variance.

Population
σ² = (1/N) Σ(xᵢ − μ)² σ = √σ²
Sample
s² = (1/(N−1)) Σ(xᵢ − x̄)² s = √s²
GATE trap — don't automatically divide by N

These are two different quantities, not two notations for the same thing. Population standard deviation (σ) divides by N — used when the data given IS the entire population. Sample standard deviation (s) divides by N−1 (Bessel's correction) — used when the data is a sample drawn from a larger population, and dividing by N−1 instead of N corrects the bias that comes from estimating spread around the sample's own mean x̄ rather than the true (unknown) population mean μ. Read the question carefully: if it explicitly says "sample standard deviation" or "sample variance," you MUST divide by N−1, not N — silently defaulting to N is one of the most common, entirely avoidable errors in this topic.

Linear Transformations

If a new dataset Y is created by applying a linear transformation Y = aX + b to dataset X:

Mean(Y) = a · Mean(X) + b Median(Y) = a · Median(X) + b Mode(Y) = a · Mode(X) + b σ(Y) = |a| · σ(X) (Adding a constant does NOT affect standard deviation)
GATE trap

GATE questions often test your choice of average. If the data is highly skewed (e.g., salaries in a company, where a few people make vastly more than others), the Median is the best measure of central tendency, not the Mean, because the Mean will be artificially pulled upward by the outliers.

Practice — GATE style (original)

6 questions
Q1 Find the median of: 12, 7, 3, 14, 9, 21.

First sort the data: 3, 7, 9, 12, 14, 21. n=6 (even), so median is the average of the 3rd and 4th terms: (9+12)/2 = 10.5.

Answer: 10.5

Q2 A dataset has a mean of 45 and a median of 42. Estimate the mode using the empirical relationship.

Mode ≈ 3(Median) − 2(Mean) = 3(42) − 2(45) = 126 − 90 = 36.

Answer: 36

Q3 The mean and standard deviation of a dataset are 50 and 8, respectively. If every value is multiplied by 2 and then increased by 5, find the new mean and standard deviation.

New mean = 2(Old Mean) + 5 = 2(50) + 5 = 105.

New std dev = |2|(Old Std Dev) = 2(8) = 16. (The +5 shift doesn't affect spread).

Answer: Mean = 105, SD = 16

Q4 Why is standard deviation preferred over variance in practical reporting?

Standard deviation has the same units as the original data (e.g., meters, dollars), whereas variance is in squared units, making SD much easier to interpret.

Answer: It has the same units as the data

Q5 If all values in a dataset are identical, what are the variance and standard deviation?

If all values are identical, they all equal the mean. Thus (xᵢ − μ) = 0 for all i. The spread is zero.

Answer: 0

Q6 A sample of 5 exam scores is {60, 70, 80, 90, 100}. Find the sample variance (not population variance).

Sample mean x̄ = (60+70+80+90+100)/5 = 400/5 = 80. Squared deviations: (−20)²=400, (−10)²=100, 0²=0, 10²=100, 20²=400 → sum = 1000. Since this is explicitly a SAMPLE, divide by N−1 = 4, not N = 5: s² = 1000/4 = 250.

Answer: s² = 250 (dividing by N−1=4; dividing by N=5 would give the wrong value 200, a population variance the question didn't ask for)

Probability Rules

Addition: P(A∪B) = P(A)+P(B)−P(A∩B). Multiplication: P(A∩B) = P(A)P(B|A). Independence: P(A∩B) = P(A)P(B).

Conditional Independence

P(A∩B|C) = P(A|C)P(B|C). Conditional independence given C does NOT imply unconditional independence, and vice versa — they're separate properties.

Bayes' Theorem

P(Aᵢ|B) = [ P(B|Aᵢ)P(Aᵢ) ] / ∑[P(B|Aⱼ)P(Aⱼ)]. Useful for reversing conditionals.

Expectation Properties

E[aX+b] = aE[X]+b. Var(aX+b) = a²Var(X). E[X+Y]=E[X]+E[Y]. General: Var(X+Y) = Var(X)+Var(Y)+2Cov(X,Y).

Covariance & Correlation

Cov(X,Y) = E[XY]−E[X]E[Y]. ρ = Cov(X,Y)/(σ_Xσ_Y), −1≤ρ≤1 — defined only when σ_X>0 and σ_Y>0 (a constant variable has undefined, not zero, correlation). Cov=0 (or ρ=0) does NOT imply independence — only rules out a linear relationship (e.g. Y=X² with symmetric X).

Binomial B(n,p)

P(X=k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ. Mean = np. Var = np(1−p).

Poisson(λ)

P(X=k) = e⁻λλᵏ/k!. Mean = λ. Var = λ. Used for rare events. Mean=Var is necessary for Poisson, NOT sufficient to conclude it.

Geometric(p)

P(X=k) = (1−p)ᵏ⁻¹p, k≥1 (trials-to-first-success form). Mean = 1/p. Var = (1−p)/p². The only discrete memoryless distribution.

Uniform U(a,b)

f(x) = 1/(b−a). Mean = (a+b)/2. Var = (b−a)²/12.

Exponential Exp(λ)

f(x) = λe⁻λˣ. Mean = 1/λ. Var = 1/λ². Only continuous memoryless dist.

Normal N(μ,σ²)

Bell curve. Standardize using Z = (X−μ)/σ to use Z-tables. 68-95-99.7 rule.

Central Tendency

Mean (avg), Median (middle, robust to outliers), Mode (most freq). Mode ≈ 3Median − 2Mean.

Linear Transform

Y = aX+b ⇒ Mean changes by aX+b, but Std Dev changes ONLY by |a| (shift doesn't affect spread).

Population vs Sample SD — don't auto-divide by N

Population: σ² = (1/N)Σ(xᵢ−μ)². Sample: s² = (1/(N−1))Σ(xᵢ−x̄)². If the question says "sample," divide by N−1, not N.

Q1 P(A)=0.5, P(B)=0.6, A and B independent. Find P(A∪B).

P(A∩B) = (0.5)(0.6) = 0.3. P(A∪B) = 0.5 + 0.6 − 0.3 = 0.8.

Answer: 0.8

Q2 A discrete RV X has Poisson distribution. If E[X]=4, what is Var(2X)?

For Poisson, Var(X) = E[X] = 4. Var(2X) = 2²Var(X) = 4(4) = 16.

Answer: 16

Q3 Exponential RV X has mean 10. Find P(X > 20 | X > 10).

By memoryless property, P(X > 20 | X > 10) = P(X > 10). Mean = 10 ⇒ λ = 1/10. P(X > 10) = e⁻⁽¹/¹⁰⁾⁽¹⁰⁾ = e⁻¹.

Answer: e⁻¹

Q4 The variance of data set X is 25. If each value is decreased by 10, what is the new standard deviation?

Decreasing by 10 is a shift (b=−10), which doesn't change variance. Var = 25, so Standard Deviation = √25 = 5. (Never negative).

Answer: 5

Q5 F(x) is the CDF of continuous RV X. Find P(a < X ≤ b).

By definition of CDF, P(X ≤ b) = F(b). To find interval (a, b], we subtract P(X ≤ a). So P(a < X ≤ b) = F(b) − F(a).

Answer: F(b) − F(a)
