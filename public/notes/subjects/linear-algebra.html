Matrices — Types & Operations

SPECIAL MATRICES · RANK · OPERATIONS · TRANSPOSE PROPERTIES

What GATE actually tests here

Matrices themselves rarely carry a full question — they're the language the rest of the syllabus (determinants, eigenvalues, systems) is written in. GATE tests whether you instantly recognize special matrix types and their guaranteed properties, since that recognition shortcuts otherwise long computations.

Special matrices — properties GATE relies on

The eigenvalue guarantees below (real, purely imaginary, orthonormal rows/columns) specifically assume a real matrix — i.e. all entries are real numbers, which is the standard GATE setting unless a question explicitly introduces complex entries. Stated for complex matrices, the corresponding guarantees actually belong to the broader classes Hermitian, skew-Hermitian, and unitary matrices instead.

TypeDefinitionKey guaranteed property (for a real matrix)
SymmetricA = AᵀEigenvalues always real
Skew-symmetricA = −AᵀDiagonal = 0; eigenvalues purely imaginary or 0
OrthogonalA·Aᵀ = Idet(A) = ±1; rows/cols form an orthonormal set (unit length, mutually perpendicular)
IdempotentA² = AEigenvalues are only 0 or 1
NilpotentAᵏ = 0 for some kAll eigenvalues are 0
InvolutoryA² = IEigenvalues are only +1 or −1
DiagonalNon-zero entries only on diagonalEigenvalues = diagonal entries themselves
Upper/Lower triangularZeros above/below diagonalEigenvalues = diagonal entries; det = product of diagonal
GATE trap

"Symmetric ⇒ real eigenvalues" is a one-way guarantee, and it's specifically a statement about real symmetric matrices. A matrix can have all-real eigenvalues without being symmetric at all — never use the converse. And if the matrix has complex entries, being symmetric (A=Aᵀ, without conjugation) no longer guarantees real eigenvalues; that stronger guarantee belongs to Hermitian matrices (A = A͞ᵀ) instead.

Rank of a matrix

Rank = number of linearly independent rows (equivalently, columns) = size of the largest non-zero minor (sub-determinant).

Computing rank fast

Reduce to row-echelon form via elementary row operations. Rank = number of non-zero rows remaining. Row operations never change rank.

Bounds

For an m×n matrix: rank ≤ min(m, n). A square n×n matrix has rank n iff it is invertible (non-singular).

Transpose & multiplication rules

(Aᵀ)ᵀ = A (A + B)ᵀ = Aᵀ + Bᵀ (AB)ᵀ = Bᵀ·Aᵀ (order reverses!) (kA)ᵀ = k·Aᵀ (ABC)ᵀ = Cᵀ·Bᵀ·Aᵀ
Multiplication is not commutative

AB ≠ BA in general, even when both products are defined and same-sized. GATE frequently builds a "which of these is always true" MCQ around this — only special cases (e.g. A and A⁻¹, or two diagonal matrices) commute.

Matrix inverse — existence & formula (2×2, 3×3)

A square matrix A is invertible iff det(A) ≠ 0. For a 2×2 matrix:

A = [a b; c d] ⇒ A⁻¹ = 1/det(A) · [d −b; −c a] where det(A) = ad − bc

For larger matrices: A⁻¹ = adj(A) / det(A), where adj(A) is the transpose of the cofactor matrix.

Practice — GATE style (original)

5 questions
Q1 A 4×4 matrix has rank 3. What can you conclude about det(A)?

A square n×n matrix has full rank n iff it is invertible (det ≠ 0). Rank 3 < 4 means the matrix is singular.

Answer: det(A) = 0

Q2 If A is a 3×3 skew-symmetric matrix, what is the value of det(A)?

For skew-symmetric A: det(A) = det(Aᵀ) = det(−A) = (−1)ⁿ·det(A). For odd n (n=3), this gives det(A) = −det(A), forcing det(A) = 0.

Answer: det(A) = 0

Q3 Find the inverse of A = [2 1; 1 1].

det(A) = 2(1) − 1(1) = 1. A⁻¹ = (1/1)·[1 −1; −1 2] = [1 −1; −1 2].

Answer: A⁻¹ = [1 −1; −1 2]

Q4 Is it possible for AB = BA when A and B are both diagonal matrices of the same size?

Yes — diagonal matrices always commute, since multiplying two diagonal matrices just multiplies corresponding diagonal entries element-wise, regardless of order.

Answer: Yes, always commute

Q5 A matrix A satisfies A² = A. What are the only possible eigenvalues of A?

If Av = λv, then A²v = λ²v. Since A² = A, λ²v = λv ⇒ λ² = λ ⇒ λ(λ−1) = 0.

Answer: λ = 0 or λ = 1 (idempotent matrix)

Determinants

PROPERTIES · COFACTOR EXPANSION · EFFECT OF ROW OPS

Core properties GATE tests directly

Operation / conditionEffect on determinant
Swap two rows/columnsDeterminant changes sign
Multiply one row by scalar kDeterminant scales by k
Multiply entire n×n matrix by kDeterminant scales by kⁿ
Add multiple of one row to anotherDeterminant unchanged
Two rows/columns identical or proportionalDeterminant = 0
Transpose: det(A) vs det(Aᵀ)Equal — det(A) = det(Aᵀ)
Multiplicative & inverse relations
det(AB) = det(A)·det(B) det(A⁻¹) = 1 / det(A) det(kA) = kⁿ · det(A) (n×n matrix) det(A) = product of eigenvalues trace(A) = sum of eigenvalues

Cofactor expansion (Laplace expansion)

Expand along any row or column — the answer is identical regardless of which row/column you pick, so always choose the one with the most zeros.

det(A) = Σⱼ aᵢⱼ · Cᵢⱼ where Cᵢⱼ = (−1)^(i+j) · Mᵢⱼ (Mᵢⱼ = minor: delete row i, column j)
GATE trap

det(A + B) ≠ det(A) + det(B) in general — determinant is not additive. Only multiplicative relations (det(AB) = det(A)det(B)) are guaranteed.

Triangular & block matrices

For upper/lower triangular (and diagonal) matrices, det = product of the diagonal entries — this is why Gaussian elimination to triangular form is the fastest way to compute a determinant by hand for larger matrices.

Practice — GATE style (original)

5 questions
Q1 If det(A) = 5 for a 3×3 matrix A, find det(2A).

det(kA) = kⁿ·det(A) for an n×n matrix. Here n=3, k=2: det(2A) = 2³ × 5 = 8 × 5.

Answer: det(2A) = 40

Q2 A is a 3×3 matrix with det(A) = 4. Find det(A⁻¹) and det(Aᵀ).

det(A⁻¹) = 1/det(A) = 1/4. det(Aᵀ) = det(A) = 4 (transpose never changes determinant).

Answer: det(A⁻¹) = 1/4, det(Aᵀ) = 4

Q3 Evaluate det([3 0 0; 5 2 0; 7 1 4]) using the triangular shortcut.

This is lower triangular (all entries above the diagonal are 0), so det = product of diagonal entries = 3 × 2 × 4.

Answer: det = 24

Q4 If two rows of a 4×4 matrix are swapped and then one row is scaled by 3, and the original determinant was 6, what is the new determinant?

Swapping two rows flips the sign: 6 → −6. Scaling one row by 3 then multiplies by 3: −6 × 3 = −18.

Answer: −18

Q5 Matrices A and B are both 3×3 with det(A) = 2 and det(B) = −3. Find det(AB) and det(A²B⁻¹).

det(AB) = det(A)det(B) = 2 × (−3) = −6. det(A²B⁻¹) = det(A)²/det(B) = 4/(−3).

Answer: det(AB) = −6, det(A²B⁻¹) = −4/3

03

Systems of Linear Equations

CONSISTENCY · RANK CRITERIA · GAUSSIAN ELIMINATION

The rank-based consistency test

For a system Ax = b with A the m×n coefficient matrix and [A|b] the augmented matrix, consistency depends entirely on comparing ranks:

ConditionResult
rank(A) ≠ rank([A|b])Inconsistent — no solution
rank(A) = rank([A|b]) = n (number of unknowns)Consistent — unique solution
rank(A) = rank([A|b]) < nConsistent — infinitely many solutions (n − rank free variables)
Homogeneous systems (Ax = 0)

Always consistent (x = 0 is always a solution — the "trivial" solution). Non-trivial solutions exist iff rank(A) < n, which for a square matrix is equivalent to det(A) = 0.

Gaussian elimination — the mechanical process

Convert [A|b] to row-echelon form using elementary row operations (swap rows, scale a row, add a multiple of one row to another), then back-substitute from the bottom row upward.

Row-echelon example: [1 2 1 | 4] [1 2 1 | 4] [2 1 -1 | 1] → [0 -3 -3 | -7] (R2 → R2 − 2R1) [1 -1 2 | 3] [0 -3 1 | -1] (R3 → R3 − R1) [0 0 4 | -8] (R3 → R3 − R2)

Back-substitute: 4z = −8 ⇒ z = −2. −3y − 3(−2) = −7 ⇒ y = 13/3... (illustrative — the point is the pattern, not this specific arithmetic).

GATE trap

"Number of free variables" = n − rank(A), NOT n − (number of equations). A system with 5 equations in 4 unknowns where only 3 equations are independent still has 4 − rank = 4 − 3 = 1 free variable — the extra dependent equation doesn't add constraints.

Cramer's rule (unique-solution case only)

Valid only when det(A) ≠ 0 (square system, unique solution guaranteed):

xᵢ = det(Aᵢ) / det(A) where Aᵢ = A with column i replaced by b
When not to reach for Cramer's rule

It's computationally expensive beyond 3×3 and fails outright (division by zero) whenever det(A) = 0 — even though the system might still have infinite solutions in that case. Gaussian elimination handles every case; Cramer's rule only handles the "nice" one.

Practice — GATE style (original)

5 questions
Q1 A system Ax = b has A of size 3×3 with rank(A) = 2, and rank([A|b]) = 3. What does this tell you?

Since rank(A) ≠ rank([A|b]), the system is inconsistent — b is not in the column space of A.

Answer: No solution (inconsistent)

Q2 A homogeneous system Ax = 0 has A as a 4×4 matrix with det(A) = 0 and rank(A) = 2. How many linearly independent solutions exist?

Number of independent solutions (dimension of null space) = n − rank(A) = 4 − 2.

Answer: 2 linearly independent solutions

Q3 For what value of k does the system x + y = 2, 2x + ky = 4 have infinitely many solutions?

For infinite solutions, the two equations must be proportional: 2/1 = k/1 = 4/2. From 2/1 = 4/2 = 2, we need k/1 = 2, so k = 2. Check: second equation becomes 2x + 2y = 4, i.e., x + y = 2 — identical to the first.

Answer: k = 2

Q4 A square system Ax = b has det(A) ≠ 0. What can you say about the solution using Cramer's rule reasoning?

det(A) ≠ 0 means A is invertible, so rank(A) = n (full rank) which automatically equals rank([A|b]) since adding a column can't exceed rank n for an n×n system with unique solution — the system has exactly one solution.

Answer: Unique solution exists

Q5 A system has 4 equations in 3 unknowns. If rank(A) = 3 and rank([A|b]) = 3, is the system consistent, and how many solutions?

rank(A) = rank([A|b]) = 3 = n (number of unknowns) ⇒ consistent with a unique solution, even though there are more equations (4) than unknowns (3) — the 4th equation is simply dependent on the other three.

Answer: Consistent, unique solution

04

Eigenvalues & Eigenvectors

CHARACTERISTIC EQUATION · PROPERTIES · SPECIAL-MATRIX SHORTCUTS

The defining equation

For a square matrix A, a non-zero vector v is an eigenvector with eigenvalue λ if applying A to v just scales it — the direction doesn't change:

A·v = λ·v ⟺ (A − λI)·v = 0 (has non-trivial solution iff det(A − λI) = 0)

det(A − λI) = 0 is the characteristic equation; its roots are the eigenvalues. This is the single most frequently tested computation in this entire subject.

Worked example — 2×2 characteristic equation

A = [4 1; 2 3] det(A − λI) = det([4−λ 1; 2 3−λ]) = (4−λ)(3−λ) − 2 = λ² − 7λ + 10 = 0 ⇒ (λ−5)(λ−2) = 0 ⇒ λ = 5, λ = 2

To find the eigenvector for λ = 5: solve (A − 5I)v = 0 → [−1 1; 2 −2]v = 0 → v = [1, 1]ᵀ (any scalar multiple).

Fast checks GATE rewards

QuantityShortcut
Sum of eigenvalues= trace(A) (sum of diagonal entries)
Product of eigenvalues= det(A)
Eigenvalues of AᵀSame as eigenvalues of A
Eigenvalues of A⁻¹ (A invertible)1/λᵢ for each eigenvalue λᵢ of A
Eigenvalues of Aᵏλᵢᵏ for each eigenvalue λᵢ of A
Eigenvalues of A + kIλᵢ + k for each eigenvalue λᵢ of A
Eigenvalues of triangular/diagonal ARead directly off the diagonal — no computation needed
GATE trap — "eigenvalues of A⁻¹ = 1/λᵢ" needs A invertible

This shortcut silently assumes A is nonsingular. If A has 0 as an eigenvalue, then det(A) = product of eigenvalues = 0, so A is singular and A⁻¹ doesn't exist at all — there's nothing to take reciprocals of. The correct statement: if A is invertible (equivalently, all its eigenvalues are nonzero), then A⁻¹ exists and its eigenvalues are exactly 1/λᵢ. Always confirm no eigenvalue is 0 before applying this shortcut.

GATE trap

Eigenvalues can repeat (algebraic multiplicity > 1), but that does NOT guarantee two independent eigenvectors for that eigenvalue (geometric multiplicity can be less than algebraic multiplicity). This gap is exactly what breaks diagonalizability — see Sheet 05.

Eigenvectors for distinct eigenvalues

Eigenvectors corresponding to distinct eigenvalues are always linearly independent. This is why an n×n matrix with n distinct eigenvalues is guaranteed diagonalizable.

Practice — GATE style (original)

5 questions
Q1 A 3×3 matrix has trace = 9 and two of its eigenvalues are 2 and 3. Find the third eigenvalue.

Sum of eigenvalues = trace = 9. Third eigenvalue = 9 − 2 − 3.

Answer: λ₃ = 4

Q2 Find the eigenvalues of A = [2 0; 0 5].

A is diagonal, so eigenvalues are read directly off the diagonal entries — no characteristic-equation computation needed.

Answer: λ = 2, λ = 5

Q3 A matrix A has eigenvalues 1, 2, 3. Find det(A) and the eigenvalues of A⁻¹.

det(A) = product of eigenvalues = 1×2×3 = 6 ≠ 0, so A is invertible and the reciprocal-eigenvalue shortcut applies. Eigenvalues of A⁻¹ = reciprocals = 1, 1/2, 1/3.

Answer: det(A) = 6; eigenvalues of A⁻¹ are 1, 1/2, 1/3

Q4 Find the eigenvalues of A = [3 −2; 4 −1].

trace = 3 + (−1) = 2. det = 3(−1) − (−2)(4) = −3 + 8 = 5. Characteristic equation: λ² − 2λ + 5 = 0. λ = (2 ± √(4−20))/2 = 1 ± 2i.

Answer: λ = 1 + 2i, 1 − 2i (complex conjugate pair)

Q5 If A has eigenvalue λ = 3 with eigenvector v, what is the corresponding eigenvalue of A² + 2A for the same eigenvector v?

If Av = 3v, then A²v = 9v. So (A² + 2A)v = 9v + 2(3v) = 15v.

Answer: 15

Diagonalization & Cayley-Hamilton

P⁻¹AP = D · ALGEBRAIC VS GEOMETRIC MULTIPLICITY · CAYLEY-HAMILTON THEOREM

Diagonalization condition

A is diagonalizable (A = PDP⁻¹, D diagonal) iff it has n linearly independent eigenvectors for an n×n matrix. Equivalently: for every eigenvalue, geometric multiplicity (dimension of its eigenspace) must equal algebraic multiplicity (its multiplicity as a root of the characteristic polynomial).

Guaranteed diagonalizable

n distinct eigenvalues, OR any real symmetric matrix (always diagonalizable, and by an orthogonal matrix — spectral theorem).

Not diagonalizable

A repeated eigenvalue whose eigenspace dimension is less than its multiplicity. Classic example: [1 1; 0 1] has eigenvalue 1 (multiplicity 2) but only 1 independent eigenvector.

Why diagonalization matters — matrix powers

Once A = PDP⁻¹, computing Aᵏ becomes trivial since D is diagonal:

Aᵏ = P·Dᵏ·P⁻¹ where Dᵏ just raises each diagonal entry to the power k

This is the standard route for "find A¹⁰⁰" or "find a closed form for a linear recurrence" style questions.

Cayley-Hamilton theorem 🟡 supporting / historical

Not explicitly named in the revised GATE CSE 2027 Linear Algebra syllabus (matrices, determinants, systems of linear equations, eigenvalues/eigenvectors, LU decomposition) — kept here because it's a genuinely useful technique (e.g. for finding A⁻¹ or high powers of A) and has appeared in past papers, but treat it as supporting material rather than an explicit syllabus item.

Every square matrix satisfies its own characteristic equation. If the characteristic polynomial is p(λ) = λⁿ + c₁λⁿ⁻¹ + ... + cₙ, then:

p(A) = Aⁿ + c₁Aⁿ⁻¹ + ... + cₙI = 0 (the zero matrix)
Practical use — finding A⁻¹ without cofactors

For a 2×2 matrix with characteristic equation λ² − (trace)λ + det = 0, Cayley-Hamilton gives A² − (trace)A + det·I = 0. Rearranging: A⁻¹ = [(trace)I − A] / det(A) — often faster than the adjugate method.

GATE trap

Cayley-Hamilton is also the standard trick for reducing high powers of A: express Aⁿ (for large n) in terms of lower powers of A using the characteristic equation as a substitution rule, rather than multiplying A by itself n times.

Practice — GATE style (original)

6 questions
Q1 A = [1 1; 0 1]. Is A diagonalizable? Justify using multiplicities.

Characteristic equation: (1−λ)² = 0 ⇒ λ = 1 (algebraic multiplicity 2). Solving (A−I)v=0 gives [0 1; 0 0]v = 0 ⇒ only one independent eigenvector (geometric multiplicity 1). Since 1 < 2, it fails the diagonalizability condition.

Answer: Not diagonalizable (geometric < algebraic multiplicity)

Q2 A 3×3 real symmetric matrix — can you say for certain it is diagonalizable, and by what kind of matrix P?

By the spectral theorem, every real symmetric matrix is diagonalizable, and it can be diagonalized by an orthogonal matrix (P⁻¹ = Pᵀ).

Answer: Yes, always diagonalizable by an orthogonal matrix

Q3 Using Cayley-Hamilton, find A⁻¹ for A = [2 1; 1 2].

trace = 4, det = 3. Characteristic equation: λ² − 4λ + 3 = 0 ⇒ A² − 4A + 3I = 0 ⇒ A⁻¹ = (4I − A)/3 = [(4−2) −1; −1 (4−2)]/3 = [2 −1; −1 2]/3.

Answer: A⁻¹ = (1/3)[2 −1; −1 2]

Q4 A has eigenvalues 2 and 3 (distinct, 2×2 matrix). Is it automatically diagonalizable?

Yes — distinct eigenvalues always guarantee linearly independent eigenvectors, which for a 2×2 matrix with 2 distinct eigenvalues means diagonalizability is automatic, no further check needed.

Answer: Yes, guaranteed diagonalizable

Q5 For A = [2 1; 1 2] with eigenvalues 1 and 3, find the eigenvalues of A⁵ using diagonalization reasoning (no need to find P).

Since A = PDP⁻¹, Aⁿ = PDⁿP⁻¹ — the eigenvalues of Aⁿ are simply λⁿ for each eigenvalue λ of A. So A⁵ has eigenvalues 1⁵=1 and 3⁵=243 (trace of A⁵ = 244, determinant of A⁵ = 243). Note this only gives the eigenvalues of A⁵, not the full matrix — computing the actual matrix A⁵ additionally requires the eigenvectors (to build P) or direct matrix exponentiation.

Answer: Eigenvalues of A⁵ are 1 and 243

Q5b Bonus — actually compute the full matrix A⁵ for the same A, and verify it against Q5's trace/determinant.

Write A = I + B where B = [1 1; 1 1]. Since B² = 2B, B is "idempotent up to a scalar," so Bᵏ = 2^(k−1)B for k ≥ 1. Then Aⁿ = (I+B)ⁿ = I + [(1+2)ⁿ − 1]/2 · B by binomial expansion (using Bᵏ = 2^(k-1)B for every k≥1 term). For n=5: (3⁵−1)/2 = (243−1)/2 = 121, so A⁵ = I + 121·B.

Answer: A⁵ = [122 121; 121 122] — trace = 122+122 = 244 ✓ and determinant = 122² − 121² = (122−121)(122+121) = 243 ✓, both matching Q5's eigenvalue-based prediction exactly

06

LU Decomposition

A = LU · DOOLITTLE METHOD · SOLVING SYSTEMS VIA FORWARD/BACK SUBSTITUTION

What LU decomposition is

Express a square matrix A as the product of a lower-triangular matrix L (with 1's on its diagonal, Doolittle convention) and an upper-triangular matrix U — exactly the matrix Gaussian elimination produces along the way.

A = L · U L = lower triangular, diag(L) = 1,1,...,1 U = upper triangular (the row-echelon result)

Worked example — 3×3

A = [2 3 1; 4 7 2; 2 5 4] R2 → R2 − 2R1 (multiplier 2): [2 3 1; 0 1 0; 2 5 4] R3 → R3 − 1R1 (multiplier 1): [2 3 1; 0 1 0; 0 2 3] R3 → R3 − 2R2 (multiplier 2): [2 3 1; 0 1 0; 0 0 3] = U L stores the multipliers used (below diagonal), 1's on diagonal: L = [1 0 0; 2 1 0; 1 2 1] Check: L · U = A ✓
The rule of thumb

The multiplier used to zero out entry (i,j) during elimination goes directly into L at position (i,j). U is simply the final row-echelon form. No extra computation is needed beyond the elimination you'd do anyway.

Why LU decomposition is useful — solving Ax = b

Once A = LU, solving Ax = b splits into two easy triangular solves instead of one harder elimination:

Ax = b ⟺ LUx = b Step 1: Solve Ly = b for y (forward substitution — top to bottom, trivial since diag(L)=1) Step 2: Solve Ux = y for x (back substitution — bottom to top)
Why this matters for GATE-adjacent computing

If you need to solve Ax = b for many different b vectors with the same A, you factor A = LU once, then each new b only costs two cheap triangular solves — this is the actual reason LU decomposition exists in numerical computing, and GATE occasionally frames a question around this efficiency argument.

GATE trap

LU decomposition (without row-pivoting) can fail even when A is invertible — it requires that no zero pivot appears during elimination without swapping rows. If a pivot would be zero, plain LU (as taught in the GATE syllabus) doesn't directly apply; that's a signal to recheck the matrix or use PA = LU with a permutation matrix P (this refinement is occasionally referenced but rarely the crux of a GATE question).

Practice — GATE style (original)

5 questions
Q1 Find the LU decomposition of A = [4 3; 6 3].

Eliminate: R2 → R2 − (6/4)R1 = R2 − 1.5R1 → [4 3; 0 −1.5]. So U = [4 3; 0 −1.5], and the multiplier 1.5 goes into L: L = [1 0; 1.5 1].

Answer: L = [1 0; 1.5 1], U = [4 3; 0 −1.5]

Q2 For A = LU with L = [1 0; 2 1] and U = [3 1; 0 5], find det(A).

det(A) = det(L)·det(U). det(L) = 1 (triangular, diag = 1's). det(U) = 3×5 = 15.

Answer: det(A) = 15

Q3 Why is solving Ly = b called "forward substitution" while solving Ux = y is "back substitution"?

L is lower triangular, so its first equation involves only y₁, letting you solve top-down (forward). U is upper triangular, so its last equation involves only the last unknown, letting you solve bottom-up (backward).

Answer: Determined by which unknown each triangular system isolates first

Q4 A is 3×3 and needs a row swap during elimination to avoid a zero pivot. Can standard LU (A = LU) still be found directly?

No — a zero pivot without swapping breaks the standard Doolittle LU process. A permutation matrix P is needed, giving PA = LU instead of A = LU directly.

Answer: Not directly; needs PA = LU with a permutation matrix

Q5 Given L = [1 0; 3 1], U = [2 1; 0 4], and b = [4, 14]ᵀ, solve Ax = b via LUx = b.

Step 1 (Ly=b, forward): y₁ = 4. 3y₁ + y₂ = 14 ⇒ y₂ = 14−12 = 2. Step 2 (Ux=y, backward): 4x₂ = 2 ⇒ x₂ = 0.5. 2x₁ + x₂ = 4 ⇒ 2x₁ = 3.5 ⇒ x₁ = 1.75.

Answer: x₁ = 1.75, x₂ = 0.5

Revision Sheet

EVERYTHING ON ONE SCREEN — LAST-MINUTE PASS
Rank & consistency

rank(A)≠rank([A|b]): no solution. rank=rank=n: unique. rank=rank<n: infinite solutions.

Homogeneous systems

Always consistent (x=0 works). Non-trivial solution exists iff rank(A)<n, i.e. det(A)=0 for square A.

Determinant scaling

det(kA) = kⁿ·det(A) for n×n. det(AB)=det(A)det(B). det(A⁻¹)=1/det(A). det(A)=det(Aᵀ).

Triangular shortcut

Upper/lower triangular & diagonal matrices: eigenvalues = diagonal entries; det = product of diagonal.

Characteristic equation

det(A − λI) = 0. Sum of roots = trace(A). Product of roots = det(A).

Special matrix eigenvalue rules (real matrices)

Real symmetric → real λ. Real orthogonal → det=±1. Idempotent → λ∈{0,1}. Nilpotent → λ=0. Involutory → λ∈{−1,1}.

Eigenvalue transformations

A⁻¹ → 1/λ (only if A invertible, i.e. no λ=0). Aᵏ → λᵏ. A+kI → λ+k. Aᵀ → same λ as A.

Diagonalizability

Needs n independent eigenvectors, i.e. geometric multiplicity = algebraic multiplicity for every eigenvalue. Distinct eigenvalues ⇒ automatic. Real symmetric ⇒ always (orthogonally).

Cayley-Hamilton

Every matrix satisfies its own characteristic equation: p(A) = 0. Used to find A⁻¹ or reduce high powers of A.

LU decomposition

A = LU (diag(L)=1). Solve via Ly=b (forward), then Ux=y (backward). det(A) = product of U's diagonal.

2×2 inverse

A=[a b; c d] ⇒ A⁻¹ = (1/(ad−bc))·[d −b; −c a].

Cramer's rule

xᵢ = det(Aᵢ)/det(A), only valid when det(A)≠0 (square, unique-solution case).

How to use this sheet

Read sections 01–06 once for understanding, then loop back to this page alone for every later revision pass — if any card doesn't immediately make sense, that's the section to reopen. Linear Algebra is low-weightage (2–3 marks) but high-accuracy if these shortcuts are automatic — don't over-invest study time relative to Digital Logic, DS/Algo, or OS.

Practice — rapid-fire mix (original)

5 questions
Q1 A is a 3×3 orthogonal matrix. What are the possible values of det(A)?

Orthogonal means AAᵀ = I, so det(A)·det(Aᵀ) = det(I) = 1. Since det(A) = det(Aᵀ), det(A)² = 1.

Answer: det(A) = +1 or −1

Q2 A 4×4 nilpotent matrix — what are all its eigenvalues, and what is det(A)?

Nilpotent means Aᵏ = 0 for some k. If Av=λv then Aᵏv=λᵏv=0, forcing λ=0 for every eigenvalue (since v≠0). det(A) = product of eigenvalues = 0.

Answer: All eigenvalues = 0; det(A) = 0

Q3 A system has 3 equations, 3 unknowns, and the coefficient determinant is 0, but the system is still consistent. How many solutions does it have?

det(A)=0 rules out a unique solution (Cramer's rule fails). Consistent + det(A)=0 means rank(A)=rank([A|b])<3, so the system has infinitely many solutions, not zero.

Answer: Infinitely many solutions

Q4 A has eigenvalues 2, 2, 5 for a 3×3 matrix, and is known to be diagonalizable. What is det(A) and trace(A)?

trace = sum of eigenvalues = 2+2+5 = 9. det = product of eigenvalues = 2×2×5 = 20.

Answer: trace(A) = 9, det(A) = 20

Q5 Using Cayley-Hamilton for A = [1 2; 2 1] (trace=2, det=−3), express A³ in terms of A and I.

Characteristic equation: A² − 2A − 3I = 0 ⇒ A² = 2A + 3I. Multiply both sides by A: A³ = 2A² + 3A = 2(2A+3I) + 3A = 4A + 6I + 3A = 7A + 6I.

Answer: A³ = 7A + 6I
